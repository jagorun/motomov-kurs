# motomov-kurs

Репозиторий курса Python: читаем Адонина, пишем в VS Code, растём один проект до сайта и локального RAG.

Уроки и лекции лежат на Google Drive, папка `10_Курс_Адонин_VSCode`.
Поддомен сайта появится позже — название запишем сюда.

Тема проекта пока не выбрана. Код уроков появится после выбора.

## Локально

```bash
git clone https://github.com/jagorun/motomov-kurs.git
cd motomov-kurs
```

В VS Code: File → Open Folder → эта папка.
